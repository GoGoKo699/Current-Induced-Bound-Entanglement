# Scientific reading route

A noisy channel can stop distributing distillable entanglement before it destroys every entangled state. This project asks when those two losses coincide, and whether a stationary probability current separates them without changing the damping scales.

Read [the model and channel tests](model.md), then [the constructive reversible proof](reversible_proof.md). The [circulating three-level example](cycle.md) supplies the contrasting mechanism. The [communication argument](operational.md) explains which operational task ends at the PPT transition. [Scope and examples](limitations.md) delimit the conclusions.

The proofs use established separability and distillation results, identified in [related work](../references/RELATED_WORK.md). The [verification guide](../verification/README.md) separates finite numerical evidence from the analytical statements. For a first reading, use the [worked tutorial](../learning/TUTORIAL.md).
